SHADER SANDBOX

A fragment shader is a function that runs once per pixel and knows nothing but where it is. Everything below — the plasma, the tunnel, the sphere with a shadow — is one of those, a few dozen lines long, and you can edit it while it runs.

uniform float u_time; uniform vec2 u_resolution; uniform vec2 u_mouse; uniform int u_frame; out vec4 fragColor;

The prelude above every shader declares those five names and nothing else — it is real GLSL ES 3.00, not a dialect, so what works here works in a WebGL2 project unchanged. Error line numbers are shifted back to your source, so line 3 means line 3 of what you wrote.
